# 🍱 Marmitaria

Aplicação web para consulta de cardápio e pedidos de marmitas, feita com React.

🔗 **Acesse: [vitorrom.github.io/MarmitariaDada](https://vitorrom.github.io/MarmitariaDada/)**

## Sobre o projeto

O Marmitaria é uma interface voltada para negócios de venda de marmitas, permitindo que clientes visualizem o cardápio disponível e façam seus pedidos diretamente pela aplicação.

## Funcionalidades

- Visualização do cardápio de marmitas disponíveis
- Realização de pedidos
- Interface responsiva, adaptada para desktop e mobile

## Tecnologias

- [React](https://react.dev/) (bootstrapped com [Create React App](https://create-react-app.dev/))
- [Google Fonts](https://fonts.google.com/) (Blinker, Outfit, Roboto)
- Deploy contínuo via [GitHub Pages](https://pages.github.com/)

## Rodando localmente

> ⚠️ O código-fonte original deste build não está disponível neste repositório — apenas os arquivos já compilados (pasta `static/`, `index.html`, etc.), publicados na branch `gh-pages`. Para rodar em modo de desenvolvimento, é necessário localizar o repositório-fonte do projeto.

Para apenas visualizar o build já compilado localmente:

```bash
git clone https://github.com/VitorRom/MarmitariaDada.git
cd MarmitariaDada
git checkout gh-pages
npx serve .
```
